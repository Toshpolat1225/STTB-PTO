# Koʻrinishlar va versiyalar

> **14.10.2026 dan faqat B ishlatiladi.** A (Node.js) server toʻxtatildi; uning kodi faqat dasturchi kompyuterida A↔B moslik sinovlari uchun saqlanadi. Telefonda bitta ilova — «AGMK-STTB PTO».

| | **A koʻrinish** (amaldagi) | **B koʻrinish** (IT talablari) |
|---|---|---|
| Ilova (telefon, APK) | «AGMK-STTB PTO» (`uz.agmk.sttb.pto`) | «AGMK-STTB B» (`uz.agmk.sttb.pto.b`) — ichidagi ilova aynan bir xil; alohida paket boʻlgani uchun telefonda A bilan yonma-yon turadi, maʼlumotlari alohida |
| Server | Node.js + SQLite (`ishga_tushirish.bat`, noutbuk yoki ofis kompyuteri) | Python + PostgreSQL, Docker Compose, nginx shlyuz (faqat 8443) |
| Maʼlumotlar | `data/agmk.db` | PostgreSQL (`migrate_legacy` bilan A dan koʻchiriladi) |
| Manba kodi | — | Agentlik git serveri (AGMK git), shaxsiy maʼlumot va kalitlarsiz |

Ilova ikkala serverga ham ulanadi (API bir xil — shartnoma sinovi 185/185).

**Oʻtish tartibi:** B server IT serverida ishga tushiriladi → 2–3 telefonda «AGMK-STTB B» bilan sinov (hamma A da ishlashda davom etadi) → muammo boʻlmasa eski baza `migrate_legacy` bilan koʻchiriladi va hamma B ga oʻtadi. Oʻtishdan keyin oddiy «AGMK-STTB PTO» ilovasi ham B serverga ulanishi mumkin (QR qayta skanerlanadi).

## Versiya raqami (4.0 dan boshlab)

Versiya — **ikki xonali**: `4.0`, `4.1` … `4.9`, keyin `5.0`. Bitta raqam hamma joyda: ilova (`AGMK_VERSION`), APK (`versionName`), Docker obrazi (`agmk-sttb/backend:4.0`), oflayn paket (`AGMK-STTB-4.0`), git yorligʻi (`v4.0`).
`frontend/package.json` da `agmkVersion` — shu raqam (`version` maydoni npm uchun uch xonali: `4.0.0`). Build raqami (`AGMK_BUILD`, APK `versionCode`) har yigʻishda +1.
3.x versiyalar (3.19.4 va undan oldingi) yopildi — ularning fayllari ishlatilmaydi.
